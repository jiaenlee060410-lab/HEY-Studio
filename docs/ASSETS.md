光束是面向浏览器性能的近似体积积分，不是路径追踪。墙、柱、柜台、座椅、投影机、抽屉、门、楼梯和地面碎块有物理碰撞。小碎块的阻挡体与实例化变换一致，角色可以踏过；漂浮灰尘是无碰撞粒子。可拾取薄纸与钥匙采用 sensor，承托它们的座垫、桌面、盒底有实体碰撞。门轴动画同步 kinematic Collider；投影机盒盖为 CCD 动态刚体，受重力和桌面碰撞约束。

## 多楼层资源替换

真实楼梯、门、桌面、盒盖的位置和碰撞不能只替换一边。GLB 应采用米制，保持门轴 pivot 在门边；动态盒盖用凸包或简单代理碰撞而不是动态 trimesh。楼层基准高度为 0 / 7 / 14 米。所有楼层同时保留在物理世界；不可见层只剔除绘制，不卸载碰撞或移动玩家。

模型用米作为单位，放在 `public/models/`，以 `import.meta.env.BASE_URL + 'models/name.glb'` 加载。替换时继续使用 `src/scene/layout.ts` 的坐标，并更新匹配的 Collider；不要只移动模型。贴图使用 `public/textures/`，颜色图设置 sRGB，Normal/Roughness 保持线性。

V3 新增杂物通过 `ClutterSpawner.tsx` 共用模型缓存与实例化批次，避免每件杂物增加一个绘制调用。随机种子固定，刷新时场景布局一致。薄海报的碰撞与墙面齐平；纸片和钥匙继续用独立触发盒。光束、极光远景和发光微尘不是真实固体，不设阻挡。裂缝发光是近似表面视效，不是全局光照或实时路径追踪。
