# 场景资产与替换

本版本全部为项目原创的程序化网格、贴图与字体排版，无下载的商业模型、人物或照片场景。它提供可行走的真实三维空间，但不等同于扫描级资产或《inZOI》的制作质量。

| 资产                     | 实现                                                                   | 后续高质量替换                      |
| ------------------------ | ---------------------------------------------------------------------- | ----------------------------------- |
| 混凝土、柱、破口         | 倒角网格、破边变形、破口轮廓挤出、弯曲钢筋                             | 带独立碰撞代理的破损 GLB            |
| 座椅                     | 软垫褶皱网格、扫掠扶手支架、倾倒/破损变体                              | 红绒布影院座椅 GLB                  |
| 材质                     | 512² Base Color / Normal / Roughness，厘米级凹坑、水痕、底部霉斑、布纹 | 已授权的混凝土、绒布、锈铁 PBR 套件 |
| 地面杂物                 | 不规则凸包碎片、压扁杯身、碎爆米花薄片，实例化渲染                     | 低面数扫描碎片，保留实例化          |
| 投影机、检票栏杆、胶片盒 | 分件倒角、旋转曲面、弯曲管材                                           | 有年代感的完整设备 GLB              |
| 涂鸦                     | CanvasTexture → Drei Decal；地图与墙使用同一三角形横线符号             | 授权涂鸦贴花及对应透明度图          |
| 浅积水                   | 真实平面反射，mirror / mixStrength = 0.4                               | 可增加湿润边缘贴图                  |
| 光束                     | 有界体积内 32 步光密度采样、粒子尘埃、低密度距离雾                     | 更精细的深度遮挡体积效果            |

光束是面向浏览器性能的近似体积积分，不是路径追踪。灰尘与纸屑作为地面贴近的微小装饰，不阻塞胶囊；墙、柱、柜台、座椅、投影机、铁盒等实体有独立物理碰撞。小物体触发盒是 sensor，不能充当实体障碍。

模型用米作为单位，放在 `public/models/`，以 `import.meta.env.BASE_URL + 'models/name.glb'` 加载。替换时继续使用 `src/scene/layout.ts` 的坐标，并更新匹配的 Collider；不要只移动模型。贴图使用 `public/textures/`，颜色图设置 sRGB，Normal/Roughness 保持线性。
